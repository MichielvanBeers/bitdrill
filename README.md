# Bit Drill

Daily practice for bitmasking and reading hex, as an installable PWA.

13 levels, from reading binary up to flags, read-modify-write and combined expressions. Levels unlock at 8 of the last 10 correct. Progress is stored locally in the browser.

Play: https://michielvanbeers.github.io/bitdrill/

Install on Android: open the link in Chrome, then ⋮ → Add to Home screen / Install app.
